# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | ✅ Yes (pre-release) |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for a security problem. Use GitHub's
private vulnerability reporting instead:

👉 [Report a vulnerability](https://github.com/TheBrickalista/Pycrograph/security/advisories/new)

You can expect an acknowledgement within 48 hours and a status update within 7 days.

## Scope

The Pycrograph application and its file handling (project files, image readers,
future archive import). Vulnerabilities in third-party dependencies should be
reported to their maintainers.
