# About tab

The **About** tab provides the licence, copyright and credits, and repository
and citation information. Three buttons switch what the read-only text area
below them shows; **Legal** is shown first.

| Button | Shows |
|---|---|
| **Legal** | The full GNU General Public License v3 (GPL-3.0-only) text, from the copy bundled with the app |
| **Copyright & Credits** | The copyright line, the GPLv3 statement, the third-party libraries bundled with Pycrograph and their licences, then the full third-party notices (versions, copyright lines and licence texts) |
| **Repository** | The version, the source-code and issue-tracker URLs, and how to cite Pycrograph |

## Citing Pycrograph

The **Repository** view gives the citation, built from the `CITATION.cff` file
bundled with the app (authors, year, version):

> Boulter E, Féral CC (2026). Pycrograph (version 0.2.0) [Computer software].
> https://github.com/TheBrickalista/Pycrograph

followed by the DOI line. Every release, the 0.x betas included, is archived
on Zenodo. Until the first record exists the line reads *DOI: assigned by
Zenodo at the first release*; afterwards it gives the **concept DOI**, which
always resolves to the latest version (Zenodo also lists a DOI per version).

The same citation metadata is in
[`CITATION.cff`](https://github.com/TheBrickalista/Pycrograph/blob/main/CITATION.cff)
in the repository, which GitHub renders through **Cite this repository**.
