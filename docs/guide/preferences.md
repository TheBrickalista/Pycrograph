# Preferences

Journal page presets are data you can edit: name, width, maximum height, dpi,
font family and size, minimum line width. Built in: *Nature single column*
(89 mm) and *Nature double column* (183 mm), maximum height 170 mm, 300 dpi,
Arial 8 pt. **Add**, **Duplicate**, **Delete**, **Restore built-in presets**;
the **default preset** is used for new figures. Apply a preset to an existing
figure with *Figures › Page setup…*.

Preferences are application settings stored in the workspace
(`preferences.json`); they are not project data and are not logged. Applying a
preset to a figure is logged.
