# Pycrograph

Pycrograph is an open-source desktop application for publication figures from
fluorescence microscopy images — non-destructive and provenance-tracked. It is
the imaging sister of [PysternBlot](https://github.com/TheBrickalista/PysternBlot):
figures are re-rendered from the raw files with recorded display settings, as in
OMERO.figure, without a server.
