## Bundled licence and third-party notices

The app carries its own copy of the licence (`pycrograph/resources/LICENSE.txt`,
**About → Legal**) and of the third-party notices
(`pycrograph/resources/THIRD_PARTY_NOTICES.txt`, **About → Copyright &
Credits**). The notices list every library the apps bundle, with its version,
licence, copyright line and full licence text:

- **PySide6 / shiboken6 (Qt for Python, Qt 6)**: LGPL-3.0. The Qt libraries
  are dynamically linked and bundled unmodified as separate files, so they can
  be replaced by another build of a compatible version. The notices say where
  they are and where the Qt source code is available.
- **NumPy**: BSD-3-Clause, with the licences of the components it vendors.
- **Pillow**: MIT-CMU (HPND).
- **Pydantic** and **pydantic-core**: MIT.
- **tifffile**: BSD-3-Clause.
- **annotated-types**: MIT. **typing-extensions**: PSF-2.0.
  **typing-inspection**: MIT.
- The embedded **Python** runtime: PSF-2.0.

The notices are generated by `scripts/make_third_party_notices.py` from the
locked environment (`uv.lock`). Each release build regenerates them from its
own platform's packages before bundling. A test checks that every runtime
dependency in `uv.lock` is covered.

## Citing Pycrograph

If you use Pycrograph in published work, please cite it, with the Zenodo
concept DOI [https://doi.org/10.5281/zenodo.24404763](https://doi.org/10.5281/zenodo.24404763). It always
resolves to the latest version; each release also has its own version DOI on
Zenodo. Citation metadata is in
[`CITATION.cff`](https://github.com/TheBrickalista/Pycrograph/blob/main/CITATION.cff),
which GitHub renders through **Cite this repository**.
